# Kokulator

A simple yet elegant calculator with a graphical user interface built in Python using Tkinter.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear button to reset calculations
- Delete button to remove the last digit
- Decimal point support
- Error handling for invalid operations
- Clean and intuitive UI

## Requirements

- Python 3.x
- Tkinter (usually included with Python)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/boristom/Kokulator.git
cd Kokulator
```

2. No external dependencies needed - Tkinter comes with Python!

## Usage

Run the calculator:
```bash
python kokulator.py
```

Or on some systems:
```bash
python3 kokulator.py
```

## Project Structure

```
Kokulator/

├── README.md         # This file

```

## How to Use

1. Click number buttons to enter digits
2. Click an operation button (+, -, *, /) to select an operation
3. Enter the second number
4. Click the equals button (=) to see the result
5. Use the Clear button to start fresh
6. Use the Delete button to remove the last entered digit
